# 🚀 Инструкция по запуску

## ⚠️ Важно: Telegram Bot Token

Система требует настоящий Telegram Bot Token для работы бота. Если у вас его еще нет:

### Вариант 1: Запуск БЕЗ Telegram Bot (для тестирования)

Запустите только Backend API и 1C Integration:

```bash
# Windows
start-without-bot.bat

# Или вручную в разных терминалах:
cd services/backend-api
npm run dev

# В другом терминале:
cd services/1c-integration
npm run dev
```

Это запустит:
- ✅ Backend API на http://localhost:3001
- ✅ 1C Integration на http://localhost:3003
- ❌ Telegram Bot (требует токен)

### Вариант 2: Полный запуск С Telegram Bot

#### Шаг 1: Получите Telegram Bot Token

1. Откройте Telegram
2. Найдите **@BotFather**
3. Отправьте команду `/newbot`
4. Придумайте имя для бота (например: "Магазин Одежды")
5. Придумайте username (например: "my_shop_bot")
6. Скопируйте полученный токен (выглядит как `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

#### Шаг 2: Добавьте токен в .env

Откройте файл `.env` и замените:
```
TELEGRAM_BOT_TOKEN="your_telegram_bot_token_here"
```

на ваш токен:
```
TELEGRAM_BOT_TOKEN="1234567890:ABCdefGHIjklMNOpqrsTUVwxyz"
```

#### Шаг 3: Запустите все сервисы

```bash
npm run dev
```

Или по отдельности:
```bash
# Терминал 1
cd services/backend-api
npm run dev

# Терминал 2
cd services/telegram-bot
npm run dev

# Терминал 3
cd services/1c-integration
npm run dev
```

## ❓ Проблемы

### "404 Not Found" от api.telegram.org

Это означает, что токен не настроен или неправильный. Проверьте `.env` файл.

### "Cannot find module"

Установите зависимости:
```bash
npm install
cd services/backend-api && npm install
cd ../telegram-bot && npm install
cd ../1c-integration && npm install
```

### База данных не работает

Проверьте подключение:
```bash
cd services/backend-api
npm run db:push
npm run db:seed
```
