## 📱 Как протестировать Telegram Bot:

1. Откройте Telegram
2. Найдите вашего бота (по username, который вы указали при создании)
3. Отправьте команду `/start`
4. Попробуйте другие команды:
   - `/catalog` - Просмотр каталога товаров
   - `/orders` - Ваши заказы
   - `/help` - Справка

## 🧪 Тестирование Backend API:

- http://localhost:3001/health

### Через тестовый скрипт:
```bash
node test-api.js
```

### Через curl/Postman:

**1. Вход:**
```bash
curl -X POST http://localhost:3001/api/auth/login \
  -H "Content-Type: application/json" \
  -d "{\"username\":\"admin\",\"password\":\"admin123\"}"
```

**2. Получить список товаров:**
```bash
curl http://localhost:3001/api/products \
  -H "Authorization: Bearer YOUR_TOKEN"
```

**3. Получить список клиентов:**
```bash
curl http://localhost:3001/api/customers \
  -H "Authorization: Bearer YOUR_TOKEN"
```

