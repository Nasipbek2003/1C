# Инструкция по запуску системы после изменений

## Что было изменено:

✅ **1. Добавлена система ролей:**
   - Роль `ADMIN` - полный доступ ко всем функциям
   - Роль `OPERATOR` - доступ без управления операторами

✅ **2. Убраны кнопки автообновления** на главной странице

## Шаги для запуска:

### 1. Остановите все запущенные сервисы (если они работают)

Нажмите `Ctrl+C` в терминалах где запущены сервисы.

### 2. Запустите систему заново

Используйте один из bat-файлов:

```bash
# Запуск всей системы (включая Telegram бот)
start.bat

# Или запуск без бота
start-without-bot.bat
```

### 3. Проверьте работу системы

#### Вход как Администратор:
- URL: http://localhost:3000/login
- Логин: `admin`
- Пароль: `admin123`
- **Доступно:** Все разделы включая "Операторы"

#### Вход как Оператор:
- URL: http://localhost:3000/login
- Логин: `operator`
- Пароль: `operator123`
- **Доступно:** Главная, Клиенты, Товары, Заказы
- **НЕ доступно:** Операторы (пункт меню скрыт)

## Что проверить:

### Для администратора:

2. ✅ Можно создавать новых операторов

### Для оператора:

## Если что-то не работает:

### Проблема: Ошибка при входе
**Решение:** Убедитесь что backend API запущен на порту 3001

### Проблема: Не видно роли в интерфейсе
**Решение:** 
1. Выйдите из системы
2. Войдите заново
3. Роль должна сохраниться в localStorage

### Проблема: Оператор видит пункт "Операторы"
**Решение:**
1. Проверьте что в базе данных у оператора роль `OPERATOR`
2. Выполните скрипт: `node set-admin-role.js`
3. Перелогиньтесь

## Дополнительные скрипты:

```bash
# Установить роль администратора первому оператору
node set-admin-role.js

# Проверить операторов в базе
node check-operator-login.js
```

- **База данных:** PostgreSQL (Neon)
- **Backend API:** http://localhost:3001
- **Web Interface:** http://localhost:3000
- **Telegram Bot:** Порт 3002 (если запущен)
