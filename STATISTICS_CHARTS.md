# Графики и диаграммы в статистике

## Обзор

В раздел статистики добавлены интерактивные графики и диаграммы для визуализации данных.

## Установленные библиотеки

- **recharts** - библиотека для создания графиков и диаграмм в React

## Добавленные визуализации

### 1. Круговая диаграмма заказов

**Расположение:** Раздел "Статистика заказов"

**Что показывает:**
- Распределение заказов по статусам
- Процентное соотношение каждого статуса
- Цветовая кодировка:
  - Серый - Новые
  - Зеленый - Подтверждены
  - Синий - В обработке
  - Индиго - Отправлены
  - Изумрудный - Доставлены
  - Красный - Отменены

**Интерактивность:**
- Наведение мыши показывает точные значения
- Автоматически скрывает статусы с нулевым значением

### 2. Круговая диаграмма сообщений

**Расположение:** Раздел "Статистика сообщений"

**Что показывает:**
- Распределение сообщений по типам отправителей
- Процентное соотношение
- Цветовая кодировка:
  - Синий - От клиентов
  - Зеленый - От операторов
  - Фиолетовый - От бота

**Дополнительно:**
- Карточки с процентами от общего количества
- Точные числа для каждого типа

### 3. Линейный график заказов и выручки

**Расположение:** Раздел "Динамика за последние 7 дней"

**Что показывает:**
- Две линии на одном графике:
  - Синяя линия - количество заказов (левая ось Y)
  - Зеленая линия - выручка в сомах (правая ось Y)
- Динамика за последние 7 дней
- Точки на линиях для каждого дня

**Интерактивность:**
- Наведение мыши показывает точные значения
- Автоматическое форматирование дат
- Легенда для переключения линий

### 4. Столбчатая диаграмма новых клиентов

**Расположение:** Раздел "Динамика за последние 7 дней"

**Что показывает:**
- Количество новых клиентов по дням
- Фиолетовые столбцы с закругленными верхними углами
- Динамика регистраций за неделю

**Интерактивность:**
- Наведение мыши показывает точное количество
- Автоматическое форматирование дат

## Адаптивность

Все графики адаптивны и корректно отображаются на:
- Десктопах (большие экраны)
- Планшетах (средние экраны)
- Мобильных устройствах (маленькие экраны)

## Производительность

- Графики рендерятся только при наличии данных
- Используется `ResponsiveContainer` для автоматической подстройки размеров
- Оптимизированная перерисовка при изменении данных

## Использование

### Просмотр графиков

1. Войдите в систему
2. Перейдите в раздел "Статистика"
3. Выберите период (Сегодня, Неделя, Месяц, Все время)
4. Прокрутите страницу для просмотра всех графиков

### Интерактивность

- **Наведение мыши** - показывает детальную информацию
- **Легенда** - кликните на элемент легенды для скрытия/показа линии
- **Tooltip** - автоматически появляется при наведении

## Примеры использования

### Анализ заказов

1. Посмотрите на круговую диаграмму заказов
2. Определите, какой статус преобладает
3. Если много "Новых" - нужно обработать заказы
4. Если много "Отмененных" - выясните причину

### Анализ динамики

1. Посмотрите на линейный график
2. Определите дни с максимальными продажами
3. Сравните количество заказов и выручку
4. Планируйте маркетинговые активности на основе данных

### Анализ сообщений

1. Посмотрите на круговую диаграмму сообщений
2. Если много сообщений от клиентов - возможно нужно больше операторов
3. Если мало сообщений от операторов - проверьте их активность
4. Если много сообщений от бота - бот работает эффективно

## Технические детали

### Библиотека recharts

**Установка:**
```bash
npm install recharts
```

**Компоненты:**
- `PieChart` - круговые диаграммы
- `LineChart` - линейные графики
- `BarChart` - столбчатые диаграммы
- `ResponsiveContainer` - адаптивный контейнер
- `Tooltip` - всплывающие подсказки
- `Legend` - легенда
- `CartesianGrid` - сетка координат

### Производительность

- Графики рендерятся на стороне клиента
- Данные загружаются один раз при загрузке страницы
- При смене периода данные перезагружаются
- Оптимизация через React.memo (при необходимости)

## Часто задаваемые вопросы

**Q: Почему графики не отображаются?**
A: Убедитесь, что:
1. Backend API запущен
2. В базе есть данные
3. Нет ошибок в консоли браузера

**Q: Можно ли экспортировать графики?**
A: В текущей версии нет, но планируется в будущих обновлениях.

**Q: Почему некоторые секторы на круговой диаграмме отсутствуют?**
A: Секторы с нулевым значением автоматически скрываются для лучшей читаемости.

**Q: Как интерпретировать двойную ось Y на линейном графике?**
A: Левая ось - количество заказов, правая ось - выручка в сомах. Это позволяет сравнивать две метрики с разными масштабами.
