# Интеграция с Telegram

## Изменения в веб-интерфейсе оператора

### Что изменилось:

1. **Удалена страница веб-чата** (`/chat/[sessionId]`)
   - Операторы больше не общаются через веб-интерфейс
   - Вся коммуникация происходит через Telegram

2. **Обновлена главная страница** (`/home`)
   - Показывает список всех активных чатов
   - Каждая карточка чата содержит:
     - Имя клиента
     - Telegram ID (@username)
     - Номер телефона (если есть)
     - Время последней активности
     - Кнопку "Открыть в Telegram"

3. **Функциональность кнопки "Открыть в Telegram"**
   - При нажатии открывается Telegram с диалогом клиента
   - Использует формат ссылки: `https://t.me/{username}` (например, `https://t.me/nnbek23`)
   - Открывается в новой вкладке браузера
   - Если у клиента нет username, показывается предупреждение

### Как это работает:

1. Клиент пишет боту в Telegram
2. Создается активная сессия чата в базе данных
3. Оператор видит активный чат на главной странице
4. Оператор нажимает "Открыть в Telegram"
5. Открывается Telegram с диалогом клиента
6. Оператор отвечает клиенту напрямую в Telegram

### Структура данных:

```typescript
interface ChatSession {
  id: string;
  customerId: string;
  isActive: boolean;
  lastActivityAt: string;
  customer: {
    id: string;
    telegramUserId: string;  // Telegram ID (числовой)
    username?: string;       // Telegram username (используется для ссылки t.me/username)
    firstName?: string;
    phone?: string;
  };
}
```

### Преимущества:

- ✅ Операторы работают в привычном интерфейсе Telegram
- ✅ Не нужно поддерживать отдельный веб-чат
- ✅ Все функции Telegram доступны (стикеры, файлы, голосовые)
- ✅ Уведомления приходят напрямую в Telegram
- ✅ История переписки сохраняется в Telegram

### API endpoints:

- `GET /api/chat-sessions?active=true` - получить список активных чатов
- `GET /api/customers` - получить список клиентов
- `GET /api/orders` - получить список заказов

### Статистика на главной странице:

- Активные чаты
- Всего клиентов
- Заказов сегодня
- Общая выручка
