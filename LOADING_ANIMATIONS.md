# Анимации загрузки

## Обзор

Компонент `LoadingSpinner` предоставляет красивые анимации загрузки, которые отображаются **точно по центру экрана** во время загрузки данных.

## Ключевые особенности

✅ **Точное центрирование** - анимация всегда по центру экрана
✅ **Полноэкранный режим** - занимает весь экран с полупрозрачным фоном
✅ **Плавные анимации** - GPU-ускоренные CSS анимации
✅ **Адаптивность** - работает на всех устройствах

## Варианты анимаций

### 1. Circle (по умолчанию) - Круговая анимация ⭐

**Описание:**
- Современная круговая анимация с вращающимся кольцом
- Внешнее серое кольцо (статичное)
- Вращающееся темное кольцо (анимированное)
- Пульсирующая точка в центре
- Текст "Загрузка..." под анимацией

**Использование:**
```tsx
<LoadingSpinner variant="circle" />
```

**Особенности:**
- Плавное вращение
- Центральная точка с пульсацией
- Профессиональный вид
- **Рекомендуется для всех страниц**

### 2. Dots - Прыгающие точки

**Описание:**
- Три точки, прыгающие по очереди
- Задержка анимации для эффекта волны
- Простая и понятная анимация

**Использование:**
```tsx
<LoadingSpinner variant="dots" />
```

**Особенности:**
- Легкая анимация
- Минималистичный дизайн
- Подходит для быстрых загрузок

### 3. Pulse - Пульсирующие волны

**Описание:**
- Пульсирующий круг с волнами
- Эффект расходящихся волн
- Плавная анимация

**Использование:**
```tsx
<LoadingSpinner variant="pulse" />
```

**Особенности:**
- Мягкая анимация
- Эффект волн
- Успокаивающий вид

### 4. Default - Простое вращение

**Описание:**
- Классическое вращающееся кольцо
- Простая и быстрая анимация

**Использование:**
```tsx
<LoadingSpinner variant="default" />
```

## Размеры

Доступны три размера:

```tsx
<LoadingSpinner size="sm" />  // Маленький (12x12)
<LoadingSpinner size="md" />  // Средний (16x16)
<LoadingSpinner size="lg" />  // Большой (20x20) - по умолчанию
```

## Кастомный текст

```tsx
<LoadingSpinner text="Загрузка данных..." />
<LoadingSpinner text="Обработка..." />
<LoadingSpinner text="Пожалуйста, подождите..." />
```

## Позиционирование

**Важно:** Все анимации теперь используют `fixed inset-0`, что означает:
- ✅ Отображаются точно по центру экрана
- ✅ Занимают весь экран
- ✅ Перекрывают весь контент (z-index: 50)
- ✅ Светло-серый фон (bg-gray-50)

## Примеры использования

### В странице статистики

```tsx
if (loading) {
  return (
    <div className="flex min-h-screen bg-gray-100">
      <Sidebar />
      <div className="flex-1">
        <LoadingSpinner />
      </div>
    </div>
  );
}
```

### В странице заказов

```tsx
if (loading) {
  return <LoadingSpinner variant="dots" text="Загрузка заказов..." />;
}
```

### В модальном окне

```tsx
{isProcessing && (
  <LoadingSpinner variant="pulse" size="md" text="Обработка..." />
)}
```

## Технические детали

### CSS классы

- `fixed inset-0` - фиксированное позиционирование на весь экран
- `flex items-center justify-center` - центрирование по вертикали и горизонтали
- `bg-gray-50` - светло-серый фон
- `z-50` - высокий z-index для перекрытия контента

### Анимации Tailwind

- `animate-spin` - вращение (360° за 1 секунду)
- `animate-bounce` - прыжки
- `animate-pulse` - пульсация
- `animate-ping` - расходящиеся волны

### Цветовая схема

- Основной цвет: `slate-700` (#334155)
- Фоновый цвет: `gray-200` (#e5e7eb)
- Текст: `gray-700` (#374151)

## Рекомендации

### Когда использовать какую анимацию:

**Circle (круговая):** ⭐ Рекомендуется
- Загрузка страниц
- Загрузка больших данных
- Основная анимация для всех страниц

**Dots (точки):**
- Быстрые операции
- Отправка форм
- Короткие загрузки

**Pulse (пульсация):**
- Обработка данных
- Синхронизация
- Фоновые операции

**Default (простая):**
- Минималистичный дизайн
- Когда нужна простая анимация

## Доступность

- Анимации не мешают работе скринридеров
- Текст загрузки читается ассистивными технологиями
- Можно добавить `aria-label` при необходимости

## Производительность

- Используются CSS анимации (GPU-ускоренные)
- Нет JavaScript анимаций
- Минимальное влияние на производительность
- Плавная работа на всех устройствах
