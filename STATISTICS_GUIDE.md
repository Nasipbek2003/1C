# Руководство по статистике

## Обзор

Раздел статистики предоставляет полную аналитику по работе системы, включая данные о клиентах, заказах, товарах, сообщениях и уведомлениях.

## Доступ к статистике

1. Войдите в систему как оператор или администратор
2. В боковом меню выберите **"Статистика"**
3. Выберите период для анализа:
   - **Сегодня** - данные за текущий день
   - **Неделя** - данные за последние 7 дней
   - **Месяц** - данные за последние 30 дней
   - **Все время** - полная статистика

## Разделы статистики

### 1. Общая статистика

**Всего клиентов**
- Общее количество зарегистрированных клиентов
- Количество новых клиентов за выбранный период

**Заказов**
- Общее количество заказов за период
- Средний чек (средняя сумма заказа)

**Выручка**
- Общая выручка за период в сомах

**Активные чаты**
- Количество активных диалогов с клиентами
- Общее количество сообщений за период

### 2. Статистика заказов

Показывает распределение заказов по статусам:

- **Новые** - только что созданные заказы
- **Подтверждены** - заказы, подтвержденные оператором
- **В обработке** - заказы в процессе сборки
- **Отправлены** - заказы переданы в доставку
- **Доставлены** - успешно доставленные заказы
- **Отменены** - отмененные заказы

### 3. Статистика товаров

**Всего товаров**
- Общее количество товаров в каталоге

**Низкий запас**
- Товары с остатком менее 10 штук
- Требуют пополнения запасов

**Нет в наличии**
- Товары с нулевым остатком
- Требуют срочного пополнения

**Топ-5 товаров**
- Самые популярные товары по количеству заказов
- Показывает:
  - Название и категорию товара
  - Количество заказов
  - Общее количество проданных единиц
  - Изображение товара

### 4. Статистика сообщений

Распределение сообщений по типам отправителей:

- **От клиентов** - сообщения от покупателей
- **От операторов** - ответы операторов
- **От бота** - автоматические сообщения бота

### 5. Статистика по дням

Таблица с данными за последние 7 дней:

- **Дата** - день недели и дата
- **Заказы** - количество заказов за день
- **Выручка** - выручка за день в сомах
- **Новые клиенты** - количество новых регистраций

### 6. Уведомления

**Ожидают отправки**
- Уведомления в очереди на отправку

**Ошибки отправки**
- Уведомления, которые не удалось отправить
- Требуют внимания администратора

## API Endpoint

### GET /api/statistics

Получить статистику за указанный период.

**Query параметры:**
- `period` - период для анализа (today, week, month, all)

```bash
GET /api/statistics?period=week
Authorization: Bearer <token>
```

## Использование статистики

### Для операторов

1. **Мониторинг активности**
   - Отслеживайте количество активных чатов
   - Проверяйте количество новых заказов

2. **Контроль запасов**
   - Следите за товарами с низким запасом
   - Информируйте администратора о товарах без остатка

3. **Анализ популярности**
   - Изучайте топ товаров
   - Рекомендуйте популярные товары клиентам

### Для администраторов

1. **Финансовый анализ**
   - Отслеживайте выручку по периодам
   - Анализируйте средний чек
   - Сравнивайте показатели по дням

2. **Управление запасами**
   - Планируйте закупки на основе данных о запасах
   - Анализируйте популярность товаров

3. **Оптимизация работы**
   - Анализируйте загрузку операторов по количеству сообщений
   - Отслеживайте конверсию заказов
   - Выявляйте проблемы с уведомлениями

4. **Планирование**
   - Используйте данные по дням для прогнозирования
   - Определяйте пиковые дни продаж
   - Планируйте маркетинговые активности

## Рекомендации

### Еженедельный анализ

### Ежемесячный отчет

- Изучайте статистику "Месяц"
- Сравнивайте с предыдущими периодами
- Планируйте закупки и акции

## Часто задаваемые вопросы

**Q: Как часто обновляется статистика?**
A: Статистика обновляется в реальном времени при каждом обновлении страницы.

**Q: Можно ли экспортировать данные?**
A: В текущей версии экспорт не поддерживается, но планируется в будущих обновлениях.

**Q: Почему статистика "Сегодня" отличается от "Все время"?**
A: "Сегодня" показывает только данные за текущий день, "Все время" - за весь период работы системы.

**Q: Что делать с товарами без остатка?**
A: Свяжитесь с поставщиком для пополнения запасов или временно скройте товар из каталога.

**Q: Как интерпретировать средний чек?**
A: Средний чек = Общая выручка / Количество заказов. Показывает среднюю сумму одного заказа.
