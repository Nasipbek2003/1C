# Система управления магазином одежды

Полноценная система автоматизации клиентских коммуникаций с Telegram-ботом и веб-интерфейсом для операторов.

## 🎯 Возможности системы

### Для клиентов (Telegram Bot):
- 🛍️ Просмотр каталога товаров
- 📦 Отслеживание заказов
- 💬 Чат с оператором
- ❓ Автоматические ответы на вопросы
- 🔔 Уведомления о статусе заказа

### Для операторов (Web Interface):
- 👥 Управление клиентами
- 📦 Управление товарами (добавление, редактирование, удаление)
- 🛒 Обработка заказов
- 💬 Real-time чат с клиентами
- 📊 Статистика и аналитика
- 🔐 Безопасная аутентификация

## 📋 Требования

## 📱 Использование

### Telegram Bot

1. Найдите вашего бота в Telegram
2. Отправьте `/start`
3. Используйте кнопки для навигации:
   - 🛍️ **Каталог товаров** - просмотр всех товаров
   - 📦 **Мои заказы** - история заказов
   - ❓ **Помощь** - справочная информация
   - 📞 **Связаться с оператором** - начать чат

### Веб-интерфейс оператора

1. Откройте http://localhost:3000
2. Войдите с учетными данными:
   - **Администратор**: `admin` / `admin123`
   - **Оператор**: `operator` / `operator123`

3. Доступные разделы:
   - **Панель управления** - активные чаты и статистика
   - **Клиенты** - список всех клиентов
   - **Товары** - управление каталогом
   - **Заказы** - обработка заказов

### Компоненты:

1. **Backend API** (`services/backend-api`)

2. **Telegram Bot** (`services/telegram-bot`)
   - Node.js + node-telegram-bot-api
   - Обработка команд и кнопок
   - Интеграция с Backend API

3. **Web Interface** (`apps/web-interface`)

   - Real-time обновления

## 🔧 Управление товарами

### Добавление товара через веб-интерфейс:

1. Войдите как оператор/администратор
2. Перейдите в раздел "Товары"
3. Нажмите "+ Добавить товар"
4. Заполните форму:
   - Название
   - Цена
   - Описание
   - Категория
   - Размеры (через запятую)
   - Количество на складе
5. Нажмите "Добавить"

Товар сразу появится в Telegram боте!

## 📦 Обработка заказов

### Статусы заказов:

- **NEW** (Новый) - только что создан
- **CONFIRMED** (Подтвержден) - оператор подтвердил
- **PROCESSING** (В обработке) - собирается на складе
- **SHIPPED** (Отправлен) - передан в доставку
- **DELIVERED** (Доставлен) - получен клиентом
- **CANCELLED** (Отменен) - отменен

### Изменение статуса:

1. Откройте раздел "Заказы"
2. Нажмите "Подробнее" на нужном заказе
3. Выберите новый статус
4. Клиент автоматически получит уведомление в Telegram

## 🐛 Решение проблем

### Порты заняты

Если порты 3000, 3001, 3002 заняты:

```cmd
# Найти процессы
netstat -ano | findstr :3001
netstat -ano | findstr :3002
netstat -ano | findstr :3000

# Остановить процесс (замените PID на номер процесса)
taskkill /F /PID <PID>
```

### Ошибки подключения к БД

Проверьте `.env` файл:
- DATABASE_URL должен содержать правильную строку подключения
- Проверьте доступ к интернету (Neon DB в облаке)

### Telegram Bot не отвечает

1. Проверьте TELEGRAM_BOT_TOKEN в `.env`
2. Убедитесь, что Backend API запущен
3. Проверьте логи в консоли
