# 🚀 Быстрый запуск системы

## Способ 1: Автоматический запуск (рекомендуется)

Просто запустите файл:
```
start.bat
```

Этот файл автоматически:
- ✅ Очистит кэш Next.js
- ✅ Запустит все сервисы
- ✅ Покажет адреса для доступа

## Способ 2: Ручной запуск

```cmd
npm run dev
```

## 📱 Доступ к системе

После запуска откройте:

### Веб-интерфейс оператора
**URL:** http://localhost:3000

**Учетные данные:**
- Администратор: `admin` / `admin123`
- Оператор: `operator` / `operator123`

### Telegram Bot
Найдите вашего бота в Telegram и отправьте `/start`

### Backend API
**URL:** http://localhost:3001/health

## ⚠️ Если возникли ошибки

### Ошибка "Port already in use"

Остановите процессы на портах:
```cmd
netstat -ano | findstr :3000
netstat -ano | findstr :3001
netstat -ano | findstr :3002

taskkill /F /PID <номер_процесса>
```

### Ошибка "The default export is not a React Component"

Очистите кэш Next.js:
```cmd
rmdir /s /q apps\web-interface\.next
```

Затем перезапустите систему.

### Ошибка подключения к базе данных

Проверьте файл `.env`:
- DATABASE_URL должен быть правильным
- Проверьте интернет-соединение (база в облаке)

## 📊 Что запускается

1. **Backend API** (порт 3001)
   - REST API
   - WebSocket сервер
   - Подключение к PostgreSQL

2. **Telegram Bot** (порт 3002)
   - Обработка сообщений от клиентов
   - Интеграция с Backend API

3. **Web Interface** (порт 3000)
   - Next.js приложение
   - Интерфейс для операторов

## 🎯 Первые шаги

1. **Откройте веб-интерфейс:** http://localhost:3000
2. **Войдите** с учетными данными `admin` / `admin123`
3. **Добавьте товары** в разделе "Товары"
4. **Откройте Telegram** и найдите вашего бота
5. **Отправьте** `/start` боту
6. **Просмотрите каталог** через кнопку "🛍️ Каталог товаров"

## 📞 Тестирование чата

1. В Telegram боте нажмите "📞 Связаться с оператором"
2. Напишите сообщение
3. В веб-интерфейсе (http://localhost:3000) увидите активный чат
4. Нажмите "Открыть чат" и ответьте клиенту

## ✅ Проверка работы

### Backend API
```cmd
curl http://localhost:3001/health
```
Должен вернуть: `{"status":"ok","timestamp":"..."}`

### Web Interface
Откройте http://localhost:3000 - должна открыться страница входа

### Telegram Bot
Отправьте `/start` боту - должен ответить с кнопками

## 🛑 Остановка системы

Нажмите `Ctrl+C` в окне терминала
