# Анимации загрузки

## Добавленные компоненты

### LoadingSpinner Component

Универсальный компонент загрузки с тремя вариантами анимации.

**Расположение:** `apps/web-interface/app/components/LoadingSpinner.tsx`

#### Варианты использования:

```tsx
// 1. Стандартная анимация (вращающееся кольцо с пульсирующим центром)
<LoadingSpinner />

// 2. Анимация с точками
<LoadingSpinner variant="dots" />

// 3. Пульсирующая анимация
<LoadingSpinner variant="pulse" />

// С кастомным текстом
<LoadingSpinner text="Загрузка данных..." />

// С разными размерами
<LoadingSpinner size="sm" />  // Маленький
<LoadingSpinner size="md" />  // Средний (по умолчанию)
<LoadingSpinner size="lg" />  // Большой
```

#### Параметры:

- **variant**: `'default' | 'dots' | 'pulse'` - тип анимации
- **size**: `'sm' | 'md' | 'lg'` - размер спиннера
- **text**: `string` - текст под анимацией (по умолчанию "Загрузка...")

## Где используется

### 1. Главная страница (`/home`)
- Стандартная анимация при загрузке дашборда
- Показывается пока загружаются статистика и активные чаты

### 2. Страница клиентов (`/customers`)
- Стандартная анимация при загрузке списка клиентов

### 3. Страница товаров (`/products`)
- Стандартная анимация при загрузке каталога товаров

### 4. Страница заказов (`/orders`)
- Стандартная анимация при загрузке списка заказов

### 5. Страница операторов (`/operators`)
- Стандартная анимация при загрузке списка операторов
- Доступна только для администраторов

### 6. Страница чата (`/chat/[sessionId]`)
- Стандартная анимация при загрузке истории чата

### 7. Страница входа (`/login`)
- Анимированная кнопка входа с вращающимся спиннером
- Показывается во время процесса авторизации

## Стилизация

Все анимации используют:
- **Цвет:** slate-700 (темно-серый) для основных элементов
- **Фон:** slate-200 (светло-серый) для вспомогательных элементов
- **Анимации Tailwind CSS:**
  - `animate-spin` - вращение
  - `animate-pulse` - пульсация
  - `animate-bounce` - подпрыгивание
  - `animate-ping` - расширяющиеся круги

## Преимущества

✅ **Единообразие** - одинаковый стиль на всех страницах
✅ **Гибкость** - три варианта анимации на выбор
✅ **Адаптивность** - три размера для разных контекстов
✅ **UX** - пользователь видит что система работает
✅ **Простота** - легко использовать и настраивать

## Примеры кода

### Базовое использование в странице:

```tsx
import LoadingSpinner from '../components/LoadingSpinner';

export default function MyPage() {
  const [loading, setLoading] = useState(true);

  if (loading) {
    return (
      <div className="flex min-h-screen bg-gray-100">
        <Sidebar />
        <div className="flex-1">
          <LoadingSpinner />
        </div>
      </div>
    );
  }

  return (
    // ... основной контент
  );
}
```

### Использование в кнопке:

```tsx
<button
  type="submit"
  disabled={loading}
  className="bg-slate-700 hover:bg-slate-800 text-white font-bold py-2 px-4 rounded disabled:opacity-50 flex items-center justify-center"
>
  {loading ? (
    <>
      <svg className="animate-spin -ml-1 mr-3 h-5 w-5 text-white" xmlns="http://www.w3.org/2000/svg" fill="none" viewBox="0 0 24 24">
        <circle className="opacity-25" cx="12" cy="12" r="10" stroke="currentColor" strokeWidth="4"></circle>
        <path className="opacity-75" fill="currentColor" d="M4 12a8 8 0 018-8V0C5.373 0 0 5.373 0 12h4zm2 5.291A7.962 7.962 0 014 12H0c0 3.042 1.135 5.824 3 7.938l3-2.647z"></path>
      </svg>
      Загрузка...
    </>
  ) : (
    'Отправить'
  )}
</button>
```

## Кастомизация

Если нужно изменить цвета, отредактируйте файл `LoadingSpinner.tsx`:

```tsx
// Изменить цвет с slate-700 на другой:
className="bg-blue-700 rounded-full animate-pulse"

// Изменить цвет кольца:
className="border-blue-200 border-t-blue-700 rounded-full animate-spin"
```

## Производительность

- Все анимации используют CSS-трансформации (GPU-ускорение)
- Минимальное влияние на производительность
- Плавная работа даже на слабых устройствах
