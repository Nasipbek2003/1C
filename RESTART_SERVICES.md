# Инструкция по перезапуску сервисов

## Быстрый перезапуск всех сервисов

1. **Остановите все запущенные сервисы:**
   - Нажмите `Ctrl+C` в каждом окне терминала
   - Или закройте все окна терминалов

2. **Запустите заново:**
   ```bash
   start.bat
   ```

## Перезапуск отдельных сервисов

### Backend API (порт 3001)

1. Остановите текущий процесс (`Ctrl+C`)
2. Запустите заново:
   ```bash
   cd services/backend-api
   npm run dev
   ```

### Web Interface (порт 3000)

1. Остановите текущий процесс (`Ctrl+C`)
2. Запустите заново:
   ```bash
   cd apps/web-interface
   npm run dev
   ```

### Telegram Bot (порт 3002)

1. Остановите текущий процесс (`Ctrl+C`)
2. Запустите заново:
   ```bash
   cd services/telegram-bot
   npm run dev
   ```

## После добавления новых роутов

Если вы добавили новые API роуты (например, `/api/statistics`):

1. **Обязательно перезапустите Backend API:**
   ```bash
   cd services/backend-api
   npm run dev
   ```

2. **Проверьте, что роут работает:**
   - Откройте браузер
   - Перейдите на `http://localhost:3001/health`
   - Должен вернуться `{"status":"ok","timestamp":"..."}`

3. **Проверьте логи в консоли:**
   - Должно быть сообщение: `Backend API Service started on port 3001`
   - При запросе к `/api/statistics` должна появиться запись в логах

## Проверка работы статистики

1. **Войдите в систему:**
   - Откройте `http://localhost:3000/login`
   - Войдите как оператор или администратор

2. **Перейдите в раздел "Статистика":**
   - В боковом меню нажмите "Статистика"
   - Должна загрузиться страница с данными

3. **Если страница не загружается:**
   - Откройте консоль браузера (F12)
   - Проверьте вкладку "Network"
   - Найдите запрос к `/api/statistics`
   - Проверьте статус ответа (должен быть 200)

## Частые проблемы

### Ошибка "Cannot GET /api/statistics"

**Причина:** Backend API не запущен или роут не зарегистрирован

**Решение:**
1. Перезапустите Backend API
2. Проверьте, что в `services/backend-api/src/index.ts` есть строка:
   ```typescript
   app.use('/api/statistics', statisticsRouter);
   ```

### Ошибка 401 Unauthorized

**Причина:** Токен не передается или недействителен

**Решение:**
1. Выйдите из системы
2. Войдите заново
3. Попробуйте снова

### Ошибка 500 Internal Server Error

**Причина:** Ошибка в коде или проблема с базой данных

**Решение:**
1. Проверьте логи Backend API в консоли
2. Проверьте подключение к базе данных
3. Проверьте, что все миграции применены:
   ```bash
   cd services/backend-api
   npx prisma migrate deploy
   ```

### Страница статистики пустая

**Причина:** Нет данных в базе или ошибка загрузки

**Решение:**
1. Проверьте консоль браузера на ошибки
2. Убедитесь, что в базе есть данные:
   ```bash
   node seed-test-data.js
   ```

## Проверка портов

Убедитесь, что порты свободны:

```bash
# Windows
netstat -ano | findstr :3000
netstat -ano | findstr :3001
netstat -ano | findstr :3002
```

Если порт занят, завершите процесс или используйте другой порт.

### Web Interface

### Telegram Bot
Логи бота выводятся в консоль.

## Полная перезагрузка

Если ничего не помогает:

1. Остановите все сервисы
2. Удалите node_modules (опционально):
   ```bash
   rmdir /s /q node_modules
   rmdir /s /q services\backend-api\node_modules
   rmdir /s /q apps\web-interface\node_modules
   ```
3. Переустановите зависимости:
   ```bash
   npm install
   ```
4. Запустите заново:
   ```bash
   start.bat
   ```
