## 📱 Как протестировать:

### 1. Telegram Bot

Откройте Telegram и найдите вашего бота, затем:

```
/start - Начать работу
/catalog - Просмотр каталога (5 товаров)
/orders - Ваши заказы
/help - Справка
```

Также можете просто написать сообщение боту - он сохранит его в базу данных.

### 2. Backend API

**Health Check:**
```
http://localhost:3001/health
```

**Вход (получить токен):**
```bash
curl -X POST http://localhost:3001/api/auth/login \
  -H "Content-Type: application/json" \
  -d "{\"username\":\"admin\",\"password\":\"admin123\"}"
```

**Получить список товаров (требует токен):**
```bash
curl http://localhost:3001/api/products \
  -H "Authorization: Bearer YOUR_TOKEN_HERE"
```

**Публичные endpoints (без токена):**
- `POST /api/public/customers` - Создать клиента
- `GET /api/public/customers/telegram/:telegramUserId` - Получить клиента
- `POST /api/public/chat-sessions` - Создать чат-сессию
- `POST /api/public/messages` - Отправить сообщение

### 3. Просмотр базы данных

```bash
cd services/backend-api
npm run db:studio
```

Откроется Prisma Studio на http://localhost:5555
